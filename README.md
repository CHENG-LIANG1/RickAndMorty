# Who Dies First?

A two-player multiverse survival challenge powered by the public [Rick and Morty API](https://rickandmortyapi.com/).

The complete challenge flow supports English and Simplified Chinese. A challenge link preserves the creator's selected language for the invited friend.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The app is a client-side Vite project with no secrets or database requirements. Vercel can deploy it with the default Vite preset and `dist` output directory.
